
NAVIGATION
CTRL + B // Show/Hide activity Bar
CTRL + ALT + B // Close/Open Secondary Side Bar
CTRL + ALT + I // Open/Close Chat
CTRL + 1/2/3 // Focus Work Area
CTRL + SHIFT + P // Open Command Pallete

EDITING
CTRL + ArrowLeft/Arrow Right // Jump to next/prev word
CTRL + L // Select Line
CTRL + SHIFT + K // Delete Line
SELECTWORD then CTRL + D // Edit multiple words

QUOKKA
CTRL + SHIFT + P then Quokka.js: START on current file
